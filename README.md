A personal portfolio showcasing my work in Python backend engineering, computer vision, data pipelines, and applied machine learning. It highlights selected projects, internship experience, technical skills, achievements, and ways to connect.

## Portfolio Features

- Responsive layout for desktop and mobile.
- Dark and light themes.
- Project carousel with previous/next navigation.
- Project screenshot previews and a horizontally navigable image gallery.
- Internship cards with expanded technology explanations.
- Resume preview modal.
- Sections for experience, projects, skills, background, education, certifications, and contact.

## Tech Stack

- React
- JavaScript
- CSS
- Google Fonts: Bricolage Grotesque and IBM Plex Mono
